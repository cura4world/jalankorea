# Jalan Korea (가칭)

EPS-TOPIK 준비생과 한국 체류 외국인 노동자를 위한 앱.

- 1차 언어: 인도네시아어
- 방향: 시험 앱이 아니라 한국 취업·생활 앱 (시험 30 / 학습 30 / 생활 40)
- 원칙: 서버 없음. 사용자가 늘어도 비용이 늘지 않는다.

## 폴더가 무엇인지

| 폴더 | 무엇이 들어가나 | 누가 건드리나 |
| --- | --- | --- |
| `app/` | 앱 소스 코드 | Claude Code |
| `content/id/` | 인도네시아어판 콘텐츠 (문항·단어·과·아티클) | 사람 (콘텐츠 작업) |
| `ui_strings.json` | 화면에 나오는 문구 (버튼 이름 등) | 사람 |
| `audio/` | 듣기 음원 파일 | 사람 (TTS 사전 생성) |
| `docs/` | 계획안, 설계서, 저작권 자료, 공단 질의 | 사람 |

핵심은 **앱은 그릇, 콘텐츠는 내용물**이라는 것. 문항을 하나 추가할 때
앱 코드는 건드리지 않는다. `content/id/exam_questions.json`에만 추가한다.

언어를 늘릴 때도 `content/vi/`, `content/ne/` 폴더를 새로 만들 뿐
`app/`은 그대로다.

## 콘텐츠 파일 규칙

### 공통
- 모든 파일 맨 위 `_meta`에 설명·개수·수정일이 있다. 내용을 고치면 `updated`도 고친다.
- 항목마다 `status`: `draft` → `review_1_done`(1차 검수 완료) → `verified`(검증단 확인 완료)

### exam_questions.json
- `source`: `original`(자체 제작, 저작권 제약 없음) / `textbook`(표준교재 인용, 원문 무변경·출처표시 필수)
- `pack`: `free`(무료 공개) / `pack01` 등 (유료)
- 유료 팩은 `source: original`만 넣는다. 저작권 안전판.

### articles.json — 필수 3필드
법률·제도 정보는 매년 바뀐다. 세 필드를 반드시 채운다.

- `sources`: 공식 출처 (고용노동부, eps.go.kr 등)
- `last_verified`: 최종 확인 연월
- `needs_check`: 아직 확인 못 한 세부 요건 목록. 비어 있어도 `[]`로 둔다.

`needs_check`가 비어 있지 않은 글은 앱에서 그 부분을 단정하지 않고
확인처를 안내하는 문장으로 처리한다.

점검 주기: 연 1회 전수 + 법령 개정 시 즉시.

## 저작권

표준교재는 공공누리 제3유형(출처표시 · 변경금지).
상업적 이용은 가능하나 **번역·개작 불가**.

- 원문을 넣을 때는 무변경 + 출처표시
- 번역본은 만들지 않는다
- 우리가 쓴 해설과 자체 제작 문항은 제약 없음

출처표시 문구는 `ui_strings.json`의 `credit` 키에 있다.
